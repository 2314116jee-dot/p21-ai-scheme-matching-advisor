==========================================================
How to Run P21 (AI Scheme-Matching Advisor) Locally
==========================================================

1. AI Provider Setup (Google Gemini & Ollama)
-----------------------------------------------
The application is configured to use Google Gemini Cloud AI by default:
- Provider: Google Gemini (gemini-2.5-flash)
- No local GPU or Ollama installation required!
- Your Gemini API Key and Project (681553723879) are active in .env.

Optional: To switch to local Ollama with DeepSeek-R1 (1.5B):
  Set AI_PROVIDER=ollama in .env, start `ollama serve`, and run:
  scripts\train-ollama-model.bat (or .\scripts\train-ollama-model.ps1)

2. Running the Application
--------------------------
Option A: Using Command Prompt (CMD)
  start-local.bat

Option B: Using PowerShell
  .\scripts\start-local.ps1

To run in Development Mode (with hot-reload):
  start-dev.bat  (or .\scripts\start-dev.ps1)

To stop running servers:
  stop.bat       (or .\scripts\stop.ps1)

3. Accessing the Features
-------------------------
- Web Application:
    http://localhost:8000
- Interactive AI Scheme Chatbot & Advisory Hub:
    http://localhost:8000/ai-assistant
- Floating AI Chatbot Widget:
    Available in the bottom-right corner of every page!
- API Swagger Documentation:
    http://localhost:8000/docs
- Health & AI Status:
    http://localhost:8000/api/health
    http://localhost:8000/api/ai/status
